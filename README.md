## ✨ الميزات الرئيسية

### ![](https://img.shields.io/badge/📅-المتابعة_اليومية_ومستجدات_الدراسة-104020?style=for-the-badge)

بطاقات حيّة تتحدّث فور إضافة أي محتوى دون إعادة تحميل الصفحة:

| القسم | ما يقدّمه |
|:---|:---|
| 📝 **الواجبات** | تصفية حسب المادة، موعد التسليم مع تنبيه ذكي («غداً»، «بعد يومين»، «قبل 3 أيام»)، وإرفاق حتى 3 صور لكل واجب مع إمكانية تحميلها |
| 🧪 **الامتحانات** | اسم الامتحان وتاريخه ووقته وملاحظاته، مرتّبة من الأقرب إلى الأبعد |
| 🎥 **الحصص والتسجيلات** | حصص مباشرة وتسجيلات برابط مباشر، مع وصول سريع إلى **قناة تسجيلات الحصص على يوتيوب** |
| 👨‍🏫 **المدرسون** | أرقام التواصل مع المدرسين، مع زر اتصال وزر واتساب |

> 🧠 **تصنيف ذكي للمواد:** «رياضيات» و«Math» و«ماث» تظهر كمادة واحدة تلقائياً.

---

### ![](https://img.shields.io/badge/🧭-الدليل_الدراسي_|_الخدمات_والروابط-315c43?style=for-the-badge)

| الخدمة | ماذا ستجد فيها |
|:---|:---|
| 🎓 **eSchool Palestine** | الموقع الرسمي، تطبيق eSchool للأندرويد، تطبيق Wise School (أندرويد وآيفون)، الدليل الإرشادي الرسمي، وتجهيز بيانات الحساب |
| 💻 **Microsoft Teams** | فتح Teams على الويب، تطبيقات الأندرويد والآيفون، وملفات وفيديوهات إرشادات الدخول |
| 🔗 **روابط المواقع المهمة** | موقع وزارة التربية وصفحتها على فيسبوك، تسجيل الطلاب، صفحات المدارس، موقع مدرستي، ومجموعات واتساب الرسمية |
| 🎧 **مركز الدعم الفني** | طلبات المساعدة وأرقام الدعم لـ eSchool وTeams، مع رسائل دعم جاهزة للنسخ |
| 📚 **الكتب الإلكترونية** | كتب الصف الحادي عشر (2010) علمي وأدبي، والرزم التعليمية من الصف الأول حتى الثاني عشر |

**وأكثر من ذلك:**

- 🎬 **فيديو شرح استخراج الشهادة** عبر eSchool مدمج داخل الموقع
- 🪪 **التحقق من رقم الهوية** (9 أرقام) قبل تجهيز بيانات الحساب
- ✉️ **مساعد رسائل الدعم:** نسيان كلمة المرور، تغيير كلمة المرور، استخراج الشهادة، وحضور الحصص، مع نسخ الرسالة وإرشادك لمكان إرسالها
- 📤 **مشاركة أي خدمة** عبر واتساب أو نسخ رابطها بنقرة واحدة
- ⚡ **اختصارات سريعة** أعلى الصفحة: eSchool، Teams، الدعم، الكتب

## ❓ الأسئلة الشائعة

**س: هل أحتاج إلى حساب لاستخدام الموقع؟**
ج: لا، الموقع مفتوح للجميع بدون تسجيل.

**س: لمن هذا الموقع؟**
ج: لطلبة فلسطين، ويركّز حالياً على طلاب «2010» (الصف الحادي عشر).

**س: ماذا لو انقطع الإنترنت؟**
ج: يعمل الموقع ويعرض آخر محتوى محفوظ، ويتحدّث تلقائياً عند عودة الاتصال.

**س: كيف أثبّت الموقع كتطبيق؟**
ج: اضغط «تثبيت» في الإشعار أو في أسفل الموقع. وعلى آيفون: من قائمة المتصفح اختر «إضافة إلى الشاشة الرئيسية».

**س: كيف أجد واجباتي بسرعة؟**
ج: اكتب اسم المادة في البحث، أو افتح «الواجبات» ورشّح حسب المادة.

**س: هل أشارك بيانات الدخول مع أحد؟**
ج: لا. غيّر كلمة المرور بعد أول دخول ولا تشاركها مع أي شخص.

**س: عندي اقتراح أو واجهت مشكلة؟**
ج: استخدم زر **«تواصل واقترح»** أسفل الموقع.

## 🇬🇧 In English

**StudyGuide Palestine** is a modern, bilingual (Arabic RTL / English) study portal for Palestinian students.

| | |
|:---|:---|
| 📅 **Daily follow-up** | Live homework (with image attachments and smart due-date badges), exams, live classes & recordings, and teacher contacts |
| 🧭 **Study directory** | eSchool, Microsoft Teams, essential links, technical support, and e-books |
| 🔎 **Unified search** | Finds services, links, and daily-follow-up content in one place |
| 📲 **Installable PWA** | Works offline, with an install prompt for new visitors |
| 🎨 **Personalization** | Light/dark mode, color themes, text scaling, and sound controls |
| 🛡️ **Admin mode** | Firebase Auth + Realtime Database, write access for the admin only |
